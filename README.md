# סוכני הסייבר — משחק בטיחות ברשת

משחק חינוכי לבני נוער שמלמד בטיחות ברשת דרך מפת משימות של **סוכן/ת בטיחות סייבר**, עם פנייה אישית לשם השחקן/ית לאורך כל המשחק.
עברית, RTL, מראה gamer. **PWA** שאפשר להתקין כאפליקציה ולשחק גם אופליין — בברירת מחדל בלי שרת ובלי איסוף מידע אישי (יש "מצב כיתה" אופציונלי, ראו פרטיות).

נוצר ע"י אלון ואורי מרקוביץ.

## 🎮 שחקו עכשיו
**https://cyber-agents-alon-markovichs-projects.vercel.app**

## 📱 התקנה כאפליקציה
- **תלמיד/ה (`index.html`):** iPhone/iPad — שיתוף ⬆️ → «הוסף למסך הבית». אנדרואיד — הצעת «התקן אפליקציה», או תפריט ⋮ → «התקן אפליקציה».
- **מורה (`index.html?teacher=1`):** אותו תהליך, אבל מתקבל אייקון, שם ומסך פתיחה נפרדים — ישירות לאזור המורה, לא למשחק. מבוסס על `manifest-teacher.webmanifest` נפרד (עם `start_url` משלו) שמוחלף דינמית ב-`<head>` כשה-URL מכיל `?teacher=1`, כך שגם ה-icon שנשמר וגם מה שנפתח בלחיצה עליו שייכים לאזור המורה.

## 🕹️ מכניקה
- מפת משימות עם פתיחה רציפה של תחנות; אפשר לחזור למפה באמצע שלב (מתקדם/ת בהמשך מאותה נקודה) ולאפס שלב בודד או את כל המשחק.
- סדר תשובות החידון מתערבב בכל פעם — אין "מיקום קבוע" לתשובה הנכונה.
- טעות מורידה לב + הסבר קצר, ותמיד אפשר לנסות שוב עד תשובה נכונה. פידבק מנוסח באופן משתנה ומעודד, בפנייה אישית.
- נקודות (10 בפעם ראשונה, 5 אחרי טעות), עלייה בדרגות, ותעודה מסכמת.
- בסיום כל תחנה — סיכום מהיר מונפש (recap) של הלקחים המרכזיים.
- לאחר התעודה: **אתגר מתקדם 🌟** — מאגר שאלות קשות ומורכבות יותר (הנדסה חברתית, הונאות תמיכה טכנית, טייפוסקווטינג ועוד). כל סבב מבטיח שאלה אחת מכל אחד מ־6 הנושאים (לא מתמקד בנושא אחד); הסבב שמור וניתן להמשיך אותו מהמפה. מוגבל לסבב אחד — לאחריו מסך סיום עם מילות שבח וכפתור שיתוף.
- מיני־משחקי המיון נתמכים בגרירה אמיתית (עכבר/מגע) לתוך תיבה או בחזרה החוצה ממנה, עם הקשה+הקשה כחלופה נגישה.
- מסך המשחק תמיד מתאים לגובה המכשיר בדיוק — ה-HUD ותפריט הניווט/התקדמות בכל שלב נשארים קבועים למעלה גם כשגוללים תוכן ארוך.
- אפקטי צליל רכים ומיוצרים בקוד (Web Audio) + רטט קליל במגע (Vibration API) + כפתור השתקה.
- בונוס רצף: כל 3 תשובות ראשונות־נכונות ברצף מזכות בנקודות בונוס והודעת עידוד מיוחדת.
- הדרכת פתיחה קצרה (מוצגת פעם אחת) לפני התחנה הראשונה.
- תרגול חוזר של תחנה שהושלמה מציג הפעם מבחר מתחלף של שאלות (לא תמיד אותן שאלות), כדי לשמור על עניין.
- אם התלמיד/ה טעה/תה בנושא כלשהו לאורך המשחק, לפני התעודה הסופית מופיע סבב חיזוק קצר עם שאלות חדשות על אותם נושאים בדיוק — כדי לוודא שההבנה מבוססת, לא רק "לחיצה על התשובה הנכונה".
- תעודת ההסמכה ניתנת להדפסה/שמירה כ-PDF (🖨️) ישירות מהדפדפן.
- אייקונים מותאמים אישית (SVG) לכל תחנה ולהודעות המשוב הקופצות, בסגנון ניאון אחיד — לא אימוג'י.

## 🏫 מצב כיתה (אופציונלי, למורים בלבד)
אין שום תפריט "מצב כיתה" שהילדים רואים — כל הזרימה קורית דרך קישור שהמורה משתף (או קוד PIN שנאמר/נכתב בכיתה):

1. מורה נכנס/ת לאזור מורה/ה (`index.html?teacher=1` — לא מקושר משום מקום במשחק עצמו, רק דרך הקישור הזה), נותן/ת שם לכיתה ומקבל/ת קוד PIN בן 6 תווים (בדיוק כמו ב-Kahoot: שם + PIN) ושני קישורים. כל כיתה שנוצרה נשמרת ברשימת "הכיתות שלי" באותו מכשיר — כדי לדעת בכל רגע כמה כיתות פתוחות וכמה תלמידים הצטרפו לכל אחת, בלי צורך בהתחברות.
2. **קישור לתלמידים** (`?class=CODE&cn=שם-הכיתה`): נשלח לכיתה כמו שהוא. ילד/ה שנכנס/ת דרכו מצטרף/ת אוטומטית ברקע — בלי מסך, בלי אישור, בלי שום פעולה נוספת — וממשיך/ה למשחק הרגיל בדיוק כמו תמיד. שם הכיתה מופיע ישירות בכותרת הראשית («סוכני הסייבר — [שם הכיתה]», באותו עיצוב הניאון) כדי שברור מיד שזו ההזמנה של המורה שלהם. אם המורה מעדיף/ה לתת רק את קוד ה-PIN בעל פה/על הלוח במקום לינק — במסך הפתיחה יש שדה "קוד כיתה מהמורה" אופציונלי; מילוי הקוד והקשה על «התחל משימה» מצרפים לאותה כיתה בדיוק כמו הלינק.
3. **קישור תוצאות להורים** (`?results=CODE`): עמוד סיכום ויזואלי מרשים של **הכיתה כולה** — כמה השתתפו, ניקוד ממוצע, ואיפה הכיתה חזקה/חלשה לפי נושא (אחוזי הצלחה עם בר צבעוני לכל אחד מ-6 העולמות). **אין שם ואין ציון אישי של אף ילד/ה על העמוד הזה** — רק תמונת מצב מצרפית של הקבוצה. אפשר לשלוח את הקישור הזה ישירות להורים.
4. **מחיקה** — מכל כיתה ברשימת "הכיתות שלי", או ממסך הכיתה עצמו, אפשר למחוק אותה לצמיתות (עם אישור). המחיקה מסירה גם את כל התלמידים ששייכים אליה — בלתי הפיכה.

בלי לינק — שום דבר לא עוזב את המכשיר, בדיוק כמו קודם. מבוסס על פרויקט Supabase נפרד וקטן (טבלאות `classes`/`students` עם RLS); קוד הכיתה עצמו הוא ה"הרשאה" — כל מי שמחזיק בו יכול להצטרף או לטעון תוצאות, בכוונה, כדי לשמור על אפס-חשבונות וזרימה פשוטה לכיתה.

## 🔒 פרטיות
בברירת מחדל המשחק לא אוסף שום מידע אישי: השם וההתקדמות נשמרים ב-`localStorage` של הדפדפן בלבד ולא נשלחים לשום מקום. רק אם ילד/ה נכנס/ת דרך קישור `?class=` שקיבל/ה מהמורה — שם, ניקוד והתקדמות נשלחים לשרת Supabase, ומשמשים אך ורק לחישוב סיכום כיתתי מצרפי (שם הילד/ה עצמו לעולם לא מוצג בשום עמוד תוצאות). אין הרשמה או חשבון בשום שלב.

## 🛠️ מבנה טכני
- אתר **סטטי**: קובץ יחיד `index.html` (עיצוב + לוגיקה), ללא שלב build.
- PWA: `manifest.webmanifest`, `sw.js` (offline shell), אייקונים תחת `/icons`.
- האייקונים נוצרים מחוץ לריפו (`sharp`) — אין `package.json` בריפו כדי ש-Vercel יגיש כסטטי.
- מצב כיתה פונה ישירות ל-REST API של Supabase (`fetch`, בלי SDK) — נשאר תלוי-תלות-אפס גם עם התכונה הזו.

### הרצה מקומית
פותחים את `index.html` בדפדפן. לבדיקת PWA/Service Worker צריך `http://localhost` (למשל `python -m http.server`).
