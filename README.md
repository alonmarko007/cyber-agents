# סוכני הסייבר 🕵️ — משחק בטיחות ברשת

משחק חינוכי לגיל 10 שמלמד בטיחות ברשת דרך מפת משימות של **סוכן/ת בטיחות סייבר**.
עברית, RTL, מראה gamer. **PWA** שאפשר להתקין כאפליקציה ולשחק גם אופליין — בלי שרת ובלי איסוף מידע אישי.

## 🎮 שחקו עכשיו
**https://cyber-agents-alon-markovichs-projects.vercel.app**

## 📱 התקנה כאפליקציה
- **iPhone/iPad (Safari):** שיתוף ⬆️ → «הוסף למסך הבית».
- **אנדרואיד (Chrome):** הצעת «התקן אפליקציה», או תפריט ⋮ → «התקן אפליקציה».

## 5 תחנות · 22 אתגרים
1. 🔒 סיסמאות
2. 🕵️ זרים ברשת
3. 🛡️ מידע אישי
4. 💬 בריונות ברשת
5. 🎣 הודעות וקישורים מפוקפקים

חידוני תרחישים + מיני־משחקי מיון, נקודות, מד חיים, תגים, ותעודת «סוכן/ת מוסמך/ת».

## 🕹️ מכניקה
- מפת משימות עם פתיחה רציפה של תחנות.
- טעות מורידה לב + הסבר קצר, ותמיד אפשר לנסות שוב עד תשובה נכונה.
- נקודות (10 בפעם ראשונה, 5 אחרי טעות), עלייה בדרגות, ותעודה מסכמת.
- אפקטי צליל מיוצרים בקוד (Web Audio) + כפתור השתקה.

## 🔒 פרטיות
המשחק לא אוסף שום מידע אישי. השם שהילד מזין נשמר ב-`localStorage` של הדפדפן בלבד ולא נשלח לשום מקום.

## 🛠️ מבנה טכני
- אתר **סטטי**: קובץ יחיד `index.html` (עיצוב + לוגיקה), ללא שלב build.
- PWA: `manifest.webmanifest`, `sw.js` (offline shell), אייקונים תחת `/icons`.
- האייקונים נוצרים מחוץ לריפו (`sharp`) — אין `package.json` בריפו כדי ש-Vercel יגיש כסטטי.

### הרצה מקומית
פותחים את `index.html` בדפדפן. לבדיקת PWA/Service Worker צריך `http://localhost` (למשל `python -m http.server`).

## 🚀 פריסה
מחובר **GitHub → Vercel**: כל `git push` לענף `main` מפרסם אוטומטית לפרודקשן.
