# סוכני הסייבר 🕵️ — משחק בטיחות ברשת

משחק חינוכי לגיל 10 שמלמד בטיחות ברשת דרך מפת משימות של "סוכן בטיחות סייבר".
עברית, RTL, מראה gamer. קובץ HTML אחד עצמאי — בלי שרת ובלי איסוף מידע אישי.
