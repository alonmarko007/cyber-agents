# סוכני הסייבר — משחק בטיחות ברשת

משחק חינוכי לבני נוער שמלמד בטיחות ברשת דרך מפת משימות של **סוכן/ת בטיחות סייבר**, עם פנייה אישית לשם השחקן/ית לאורך כל המשחק.
עברית, RTL, מראה gamer. **PWA** שאפשר להתקין כאפליקציה ולשחק גם אופליין — בברירת מחדל בלי שרת ובלי איסוף מידע אישי (יש "מצב כיתה" אופציונלי, ראו פרטיות).

נוצר ע"י אלון ואורי מרקוביץ.

## 🎮 שחקו עכשיו
**https://cyber-agents-alon-markovichs-projects.vercel.app**

## 📱 התקנה כאפליקציה
- **תלמיד/ה (`index.html`):** iPhone/iPad — שיתוף ⬆️ → «הוסף למסך הבית». אנדרואיד — הצעת «התקן אפליקציה», או תפריט ⋮ → «התקן אפליקציה».
- **ניהול כיתות (`index.html?teacher=1`):** אותו תהליך, אבל מתקבל אייקון, שם ומסך פתיחה נפרדים — ישירות למסך "הכיתות שלי", לא למשחק. מבוסס על `manifest-teacher.webmanifest` נפרד (עם `start_url` משלו) שמוחלף דינמית ב-`<head>` כשה-URL מכיל `?teacher=1`.
- **תלמיד/ה עם קישור כיתה (`index.html?class=CODE`):** כל כיתה מקבלת manifest משלה, שנוצר בזמן אמת ע"י `api/manifest.js` (פונקציית שרת קטנה בלי תלויות) — עם קוד הכיתה חתום בתוך `start_url` שלו. כך התקנה למסך הבית מקישור של כיתה מסוימת נשארת שייכת לאותה כיתה בדיוק גם בפתיחה הבאה, בלי תלות ב-`localStorage` ובלי "להתבלבל" בין כיתות — גם באנדרואיד וגם באייפון (iOS 16.4+ מכבד `start_url` מה-manifest בדיוק כמו אנדרואיד).

## 🕹️ מכניקה
- מפת משימות עם פתיחה רציפה של תחנות; אפשר לחזור למפה באמצע שלב (מתקדם/ת בהמשך מאותה נקודה) ולאפס שלב בודד או את כל המשחק.
- סדר תשובות החידון מתערבב בכל פעם — אין "מיקום קבוע" לתשובה הנכונה.
- טעות מורידה לב + הסבר קצר, ותמיד אפשר לנסות שוב עד תשובה נכונה. פידבק מנוסח באופן משתנה ומעודד, בפנייה אישית.
- נקודות (10 בפעם ראשונה, 5 אחרי טעות), עלייה בדרגות, ותעודה מסכמת.
- בסיום כל תחנה — סיכום מהיר מונפש (recap) של הלקחים המרכזיים.
- לאחר התעודה: **אתגר מתקדם 🌟** — מאגר שאלות קשות ומורכבות יותר (הנדסה חברתית, הונאות תמיכה טכנית, טייפוסקווטינג ועוד). כל סבב מבטיח שאלה אחת מכל אחד מ־6 הנושאים (לא מתמקד בנושא אחד); הסבב שמור וניתן להמשיך אותו מהמפה. מוגבל לסבב אחד — לאחריו מסך סיום עם מילות שבח וכפתור שיתוף.
- מיני־משחקי המיון נתמכים בגרירה אמיתית (עכבר/מגע) לתוך תיבה או בחזרה החוצה ממנה, עם הקשה+הקשה כחלופה נגישה.
- מסך המשחק תמיד מתאים לגובה המכשיר בדיוק — ה-HUD ותפריט הניווט/התקדמות בכל שלב נשארים קבועים למעלה גם כשגוללים תוכן ארוך.
- אפקטי צליל רכים ומיוצרים בקוד (Web Audio) + רטט קליל במגע (Vibration API) + כפתור השתקה.
- בונוס רצף: כל 3 תשובות ראשונות־נכונות ברצף מזכות בנקודות בונוס והודעת עידוד מיוחדת.
- הדרכת פתיחה קצרה (מוצגת פעם אחת) לפני התחנה הראשונה.
- תרגול חוזר של תחנה שהושלמה מציג הפעם מבחר מתחלף של שאלות (לא תמיד אותן שאלות), כדי לשמור על עניין.
- אם התלמיד/ה טעה/תה בנושא כלשהו לאורך המשחק, לפני התעודה הסופית מופיע סבב חיזוק קצר עם שאלות חדשות על אותם נושאים בדיוק — כדי לוודא שההבנה מבוססת, לא רק "לחיצה על התשובה הנכונה".
- תעודת ההסמכה ניתנת להדפסה/שמירה כ-PDF (🖨️) ישירות מהדפדפן.
- אייקונים מותאמים אישית (SVG) לכל תחנה ולהודעות המשוב הקופצות, בסגנון ניאון אחיד — לא אימוג'י.

## 🏫 כיתות ותוצאות
המטרה: לשלוח לינק לכיתה, שהכיתה תשחק, ולראות איך כל כיתה הסתדרה. אין מורים, אין הרשמה, ואין שום שדה קוד אצל התלמידים.

1. **מסך "הכיתות שלי"** (`index.html?teacher=1` — לא מקושר משום מקום במשחק): נכנסים עם **קוד אישי בן 4 ספרות** (נוצר פעם אחת במסך עצמו; אין מייל, אין סיסמה, אין שחזור — בשרת נשמר רק גיבוב שלו). המכשיר זוכר את הקוד, כך שבפעם הבאה נכנסים ישר לרשימה.
2. **כיתה חדשה:** כותבים שם ← «צור/י» ← מקבלים קישור לכיתה עם כפתור העתקה/שיתוף.
3. **הרשימה עצמה היא לוח התוצאות:** ליד כל כיתה — כמה שיחקו, כמה סיימו הכול וניקוד ממוצע, ושלושה כפתורים: 📋 קישור (העתקה מחדש), 📊 תוצאות (עמוד מפורט לפי נושא), 🗑️ מחיקה.
4. **קישור לתלמידים** (`?class=CODE&cn=שם`): מי שנכנס/ת דרכו נספר/ת אוטומטית בכיתה, בלי שום מסך נוסף. שם הכיתה מופיע בכותרת. מי שנכנס/ת דרך הכתובת הרגילה — משחק/ת רגיל, בלי כיתה ובלי שום שאלה על קוד.
5. **עמוד תוצאות** (`?results=CODE`): סיכום מצרפי של הכיתה — משתתפים, סיימו, ממוצע, ואחוזי הצלחה לכל אחד מ-6 העולמות. **אין שמות ואין ציונים אישיים.** אפשר לשלוח את הקישור הזה למי שרוצים (יש כפתור העתקה בעמוד).
6. **מצב בדיקה 🧪** — כפתור 🧪 ליד כל כיתה פותח את המשחק עם `&test=1`: סרגל עליון עם «ענה נכון», «טעות», «סיים עולם», «סיים הכול» ו«שחקן חדש». זה משחק אמיתי (אותם מסכים, ניקוד וסנכרון), כך שהתוצאות נכנסות לכיתה בדיוק כמו של תלמיד/ה — מומלץ להשתמש בכיתה ייעודית לבדיקות ולמחוק אותה אחר כך. עובד רק במכשיר שמחובר לניהול הכיתות, ושומר התקדמות נפרדת שלא נוגעת במשחק הרגיל.

מבוסס על פרויקט Supabase קטן (טבלאות `classes`/`students`/`teachers`). הגישה עוברת רק דרך פונקציות SQL מוגבלות, וכל פונקציה חושפת בדיוק את מה שהיא צריכה — הפונקציה שמזינה את התוצאות (ואת השורות ברשימת הכיתות) לא מסוגלת להחזיר שם של אף תלמיד/ה. יצירה ומחיקה של כיתות דורשות את הקוד האישי. Vercel cron יומי (`api/keepalive.js`, `vercel.json`) שומר את מסד הנתונים ער — Supabase בחינם מקפיא פרויקט אחרי שבוע בלי פעילות.

## 🔒 פרטיות
בברירת מחדל המשחק לא אוסף שום מידע אישי: השם וההתקדמות נשמרים ב-`localStorage` של הדפדפן בלבד ולא נשלחים לשום מקום. רק אם ילד/ה נכנס/ת דרך קישור כיתה (`?class=`) — שם, ניקוד והתקדמות נשלחים לשרת Supabase, ומשמשים אך ורק לחישוב סיכום כיתתי מצרפי (שם הילד/ה עצמו לעולם לא מוצג בשום עמוד תוצאות). אין הרשמה או חשבון בשום שלב — גם מי שמנהל/ת את הכיתות רק מחזיק/ה קוד.

## 🛠️ מבנה טכני
- אתר **סטטי**: קובץ יחיד `index.html` (עיצוב + לוגיקה), ללא שלב build.
- PWA: `manifest.webmanifest`, `sw.js` (offline shell), אייקונים תחת `/icons`.
- האייקונים נוצרים מחוץ לריפו (`sharp`) — אין `package.json` בריפו כדי ש-Vercel יגיש כסטטי.
- מצב כיתה פונה ישירות ל-REST API של Supabase (`fetch`, בלי SDK) — נשאר תלוי-תלות-אפס גם עם התכונה הזו.
- `api/manifest.js`: פונקציית שרת (serverless function) יחידה, בלי תלויות — Vercel מזהה כל קובץ בתיקיית `api/` ומפרסם אותו אוטומטית לצד הקבצים הסטטיים, באותו `git push`. מייצרת manifest ייעודי לכל כיתה (ראו "התקנה כאפליקציה" למעלה).

### הרצה מקומית
פותחים את `index.html` בדפדפן. לבדיקת PWA/Service Worker צריך `http://localhost` (למשל `python -m http.server`).
